This is an unfinished project. It finds the optimal thickness values for an alpha decay sail to maximize initial acceleration. At this time it only includes a few basic materials as .csv files (THE DATA IN THESE IS NOT ACCURATE! THEY ARE JUST PLACEHOLDER VALUES!).  I plan to add more materials and functions of optimzation (optimize for travel time over a given distance, optimize for minimum heat generation, etc.) and maybe add a GUI sometime in the future when I have the time. Feel free to improve on it or use it for your own research but if you do please cite me. If you want to learn more about alpha decay sails please read my previous paper on them from 2023:
https://www.tandfonline.com/doi/full/10.1080/00295639.2023.2278931
